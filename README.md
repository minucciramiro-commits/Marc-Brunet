# CODX · Landing VSL

Sitio estático listo para Vercel (sin build).

## Publicar
- **Arrastrar y soltar:** entra en vercel.com/new, elige "Deploy" sin repositorio y sube esta carpeta.
- **CLI:** dentro de esta carpeta, `npx vercel` (y `npx vercel --prod` para producción).
- **GitHub:** sube la carpeta a un repo e impórtalo en Vercel. Framework preset: "Other". Sin build command ni output directory.
